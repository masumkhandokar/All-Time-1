Khan Enterprise — PWA files

এই ZIP-এর সব ফাইল GitHub Repository-এর মূল জায়গায় (root) আপলোড করুন। পুরোনো index.html-এর জায়গায় নতুন index.html দিন এবং একই সঙ্গে manifest.webmanifest, service-worker.js, icon-192.png, icon-512.png, icon-512-maskable.png আপলোড করুন।

GitHub Pages deploy শেষ হলে Chrome-এ সাইটটি খুলে Refresh দিন। তারপর Chrome menu (⋮) থেকে Install app / Add to Home screen নির্বাচন করুন।

নোট: PWA ইনস্টলেশনের জন্য HTTPS এবং service worker সফলভাবে register হওয়া প্রয়োজন। এই প্যাকেজ Firebase rules বা database data পরিবর্তন করে না।
